# Connect after an unrecognised weigh-in to check the user list

After a factory reset or after a scale user is deleted on the scale, the scale never lists that slot as pending again. A sync-on-pending design would then simply go quiet. So when a wake reaches about 25 s and no managed slot is pending, HA still connects, reads the user list (which needs no consent) and disconnects. A missing slot or an empty list raises a repair issue. A failed consent triggers the same check. This costs one extra connection of about 10 s per unrecognised weigh-in, and lets HA tell the user that someone was not recognised and needs teaching. That notification is a per-scale option and on by default. The 25 s wait matters: the scale sleeps about 1 s after HA disconnects, so connecting before the weigh-in is final could cut it short.
